# BVE Vehicle Editor

## 主な機能

- アプリが予期せず停止するときは、お詫びメッセージを表示して終了します（JIT デバッガは起動しません）
  - そのとき、PC の情報（CPU・メモリ・OS）、直前の操作履歴（最大100件）、エラー内容をクラッシュログとして `CrashLogs` フォルダに保存します（保存できない場合は `%LOCALAPPDATA%\BveVehicleEditor\CrashLogs`）
  - メモリ破損などの危険なエラーのときは、メッセージを出さずに Windows によって終了します（`Environment.FailFast`）
- ファイルを開けない・保存できないときの理由は、日本語で表示します（例：「ほかのアプリがこのファイルを使っています。そのアプリでファイルを閉じてから、もう一度試してください。」）。英語の詳しい内容は操作履歴とクラッシュログに残します
- ウィンドウは幅 480 × 高さ 600 より小さくなりません
- 画面が小さい PC（1366×768 など）では、起動時にウィンドウが画面に収まるように縮みます
- Windows 11 風の見た目（Fluent テーマ）で、Windows のライト／ダーク設定に合わせて表示します（テキストエディタの色も切り替わります）
- テキストエディタは、ヘッダー・セクション（`[Cab]` など）・キー・数字・コメント（`;` `#`）を色分けして表示します。色はライト／ダークに合わせて切り替わります
  - スクロールバーは、行が多いとき・右にはみ出す長い行があるときだけ出ます（テキストの下の端まで押せます）
  - 「表示 → テーマ」で、システムに合わせる／ライト／ダークを選べます（選んだテーマは、アプリを閉じても覚えています）
  - 「表示 → 言語」で、日本語と English を切り替えられます（初めは Windows の表示言語に合わせます。選んだ言語は覚えています）。メニュー・タブ・入力フォーム・メッセージ・表やグラフのウィンドウなど、画面に出る文と吹き出し（ツールチップ）が英語になり、切り替えるとすぐ変わります（操作履歴とクラッシュログは日本語のままです）
  - 「表示 → フォント…」で、テキストエリアのフォントの種類と大きさを選べます。上におすすめの等幅のフォント（Consolas・BIZ UDゴシック・ＭＳ ゴシックなど、この PC に入っているもの）、その下にすべてのフォントが並び、見本で確かめられます。「初めに戻す」で Consolas・13 に戻ります（選んだフォントは閉じても覚えています）
- ショートカットキー：Ctrl+N で新規作成、Ctrl+O で Vehicle.txt を開く、Ctrl+W で閉じる、Ctrl+S ですべて保存
- 「ファイル → 閉じる」で、開いている車両ファイルを閉じて、起動した直後と同じ何も開いていない状態に戻せます（アプリは閉じません。保存していない変更があれば先に確認します）
- テキストエリアで、日本語入力（IME）の再変換が使えます。確定した日本語を選ぶか、その上にカーソルを置いて変換キーを押すと、もう一度変換し直せます（Enter・Tab で確定、Esc かマウスで別の場所を押すと取り消して元の文字のまま。確定したあと Ctrl+Z を 1 回押すと、元の文字に全部戻ります）
- 「ファイル → 新規作成…」で新しい車両ファイルを作れます。初めに名前と場所を選ぶと、1 行目の「BveTs Vehicle 2.00」と、パスが空の Parameters・PerformanceCurve・MotorNoise・Sound・Panel・Ats32・Ats64 を入れたファイルを作って開きます（同じ名前のファイルがあるときは上書きしません）。パスは各行の「参照」ボタンで選びます
- 「ファイル → 最近使った車両ファイル」から、最近開いた車両ファイル（新しい順に 10 件）を開けます（見つからなくなったものは灰色）。「起動時に前の車両ファイルを開く」にチェックを付けると、起動したときに最後に開いていた車両ファイルを開きます（初めはチェックなし）
- エクスプローラーから車両ファイルを 1 つ、ウィンドウにドラッグして離すと開きます（保存していない変更があれば、先に確認します）
- エクスプローラーで車両ファイルを右クリックして「プログラムから開く」で BveVehicleEditor を選ぶと、そのファイルを開いて起動します（初めての 1 回は「別のアプリを選択」で BveVehicleEditor.exe を選んでください）
- アプリのアイコンは、青の「電車＋書類」です（exe・ウィンドウの左上・タスクバー）
- タスクバーのアイコンを右クリックすると「最近使った車両ファイル」が出て、押すと新しいウィンドウで開きます（ピン留めもできます。Windows の設定「最近開いた項目を、スタート・ジャンプリスト・エクスプローラーに表示する」を切っていると出ません）
- 「編集」メニュー（元に戻す・やり直す・切り取り・コピー・貼り付け・すべて選択）は、今カーソルがあるテキストエリアや入力欄に効きます（使えないときは灰色）。テキストエリアで右クリックしても、同じメニューが出ます
- テキストエリアの右クリックメニューの「定型文を入れる」で、そのタブのファイルに書けるキー（Parameters = など）やセクション名（[Cab] など）を、カーソルの下の行に入れられます。すでに書かれているもの（[Cab] と [OneLeverCab] のように、どちらか 1 つしか書けない組の残りも）は、理由つきで灰色になります。Ctrl+Z で戻せます
- テキストエリアの上で Ctrl を押しながらマウスホイールを回すと、文字を大きく・小さくできます（8～40。6 つのタブでそろいます。大きさはアプリを閉じても覚えています）
- テーマ・ウィンドウの位置と大きさ（最大化も）・テキストの文字の大きさとフォント・各タブの上下の境目（スプリッター）の位置は、アプリを閉じても覚えていて、次に開いたときに使います（%LOCALAPPDATA%\BveVehicleEditor\settings.json。消すと初めの状態で開きます。覚えた位置が今の画面の外のときは、画面に収めて開きます）
- 6 つのタブのテキストのカーソルの位置は、車両ファイルごと（最近の 20 まで）に覚えていて、同じ車両ファイルを開き直すと、その位置へ戻してその行まで表示します。カーソルのある行は薄く強調されるので、テキストをクリックしていなくてもどの行か分かります
- 「デバッグ」メニューから BVE5・BVE6 を起動できます。初めて起動するときに BVE の exe を選ぶと、場所を覚えます（「場所を選び直す…」で変えられます）。保存していない変更があれば、BVE はファイルに保存した中身を読むので、先に保存するか確認します
- 「すべて保存」でファイルを上書きする前に、前の中身を控え（.bak）として残します。間違えて保存したときは、控えを開いて中身を戻せます。置き場所は %LOCALAPPDATA%\BveVehicleEditor\Backups の中の車両ファイルごとのフォルダーで、「ヘルプ → バックアップのフォルダーを開く」で開けます。「ファイル → バックアップの設定…」で、残すか・1 つのファイルにつき残す数（1～100。初めは 10。多いときは古いものから消します）を変えられます
- 自動保存：保存していない編集中の中身を、決まった間隔（初めは 5 分ごと）で控えとして %LOCALAPPDATA%\BveVehicleEditor\AutoSave に残します。車両ファイルは書き換えません（BVE が読むファイルは「すべて保存」のときだけ変わります）。ステータスバーに「自動保存中…」「自動保存しました（時:分）」と出ます。普通に閉じたときや、すべて保存して変更がなくなったときは控えを消します。「ファイル → バックアップの設定…」で、自動保存するか・間隔（1～60 分）を変えられます
- アプリが予期せず終わった（落ちた）ときは、自動保存の控えが残ります。次に起動したときや、その車両ファイルを開いたときに「控えの中身に戻しますか？」と尋ねます。「はい」で控えの中身に戻ります（まだファイルには保存していないので、確かめてから「すべて保存」してください。Ctrl+Z でファイルの中身に戻せます）。「いいえ」で控えを消して、ファイルの中身のまま開きます
- 「ヘルプ」メニュー：「バージョン情報…」でアプリのバージョン・開発者（GitHub のプロフィールへのリンク）・使っている部品の版が見られます。「ライセンスと免責事項…」ボタンで、ライセンスと免責事項も読めます。「設定のフォルダーを開く」（設定を初めに戻したいときは、この中の settings.json を消します）と「クラッシュログのフォルダーを開く」（困ったときは、この中のファイルを送ってください）もあります
- 車両ファイルは名前が自由です（Vehicle_A0.txt など）。ヘッダーのバージョンが違うファイルや、BOM 付きの UTF-8 ファイルも開けます
  - サウンドとパネルは、古い形式（1行目が「Version 1.0」）のファイルも開けます。開いた直後に、古い形式（非推奨）であることを知らせます
  - ノッチとモーター音にはヘッダーがありません。別の種類のファイル（1行目が「BveTs ～」）を選ぶと読み込みません。[Power] も [Brake] もないときは警告します
  - 車両ファイルに書かれたファイルのどれかが読めなくても（ヘッダーが合わないなど）、ほかのファイルは開けます。読めなかったファイルのタブは空になり、開いた直後に理由を知らせます（空のファイルで上書きすることはありません）。ヘッダーが合わないファイルは、BVE でも「File format is not valid.」のエラーになります。読み込めていないタブは、入力フォームとテキストが灰色になり、打てません（車両ファイルを開く前は Vehicle のタブも灰色です。参照ボタンで正しいファイルを選ぶと使えるようになります）
  - ヘッダーの後ろの文字コード指定（`:utf-8`、`:shift_jis` など。書かれていなければ UTF-8）と、ファイルの実際の文字コードが合わないときは警告します（BVE で文字化けするのを防ぐため）
  - 使えない文字（`< > " | ? *` など）、タブなどの制御文字、フォルダー名・ファイル名の最後の空白やピリオド、260 文字以上の長いパスは、ファイルを探さずに理由を知らせます（途中に空白があるパスは使えます）
- 車両ファイルを開くと、書かれているファイルパス（パラメーター・パネル・サウンド・ノッチ・モーター音・ATS プラグイン）を Vehicle タブの参照欄に表示します
  - ATS プラグインの欄は、ヘッダーが 2.00 なら「ATS 32 ビット」「ATS 64 ビット」、2.00 より前なら「ATS」です。「参照」で DLL を選ぶと、車両ファイルにパスを書き込みます
  - 参照欄にマウスを乗せるとフルパスが見えます
  - Vehicle タブのテキストを書き換えると（Ctrl+Z を含む）、少しあとに参照欄と各タブの中身も変わります（行を消すとそのタブは空になります。保存していない変更があれば確認します）
  - 見つからないファイル（ATS プラグインを含む）があれば一覧で知らせます（Title など、ファイルでないキーは探しません）
  - ヘッダーのバージョンに合わないキー（1.00 以降の Title・Author・Image・Comment、2.00 の Ats、2.00 より前の Ats32・Ats64 は BVE でエラー）や、車両ファイルのキーでない行・「=」のない行（BVE でエラー）・パスが空の行（「Parameters =」など。BVE で「指定されたファイルが見つかりません」のエラー）・同じキーが 2 回以上ある行（BVE で「同じキーのエントリが既に存在します。」のエラーになり読めない）・別のキーが同じファイルを指しているもの・ATS プラグインの DLL の種類が合わないもの（Ats32・Ats は 32 ビット版、Ats64 は 64 ビット版。違うと BVE で Cannot load.）は、参照欄の上に行番号付きで警告します。参照ボタンで合わない DLL を選んだときは、書く前に尋ねます
  - ヘッダーが 2.00 より前（または Ats64 がない）ときは、BVE6 では読めないことを知らせます（BVE6 は 64 ビットなので Ats64 が要るため）
  - ヘッダーが 2.00 より前（0.03・1.00）のときは「BveTs Vehicle 2.00 に書き直す」ボタンが出ます。押すと、確認してからヘッダーを書き換え（Shift_JIS なら :shift_jis を付ける）、Title などをコメントにし、Ats を Ats32 にします（Ctrl+Z で戻せます）。Ats64 がない・「=」のない行がある、といったことはあとで知らせます
  - 警告とお知らせは、ふだんは「⚠ 警告 2 件・お知らせ 1 件（クリックで開く）」の 1 行にまとめます。クリックで開き、開いても高さに上限があるので、下のテキストが狭くなりません
    - パラメーター・パネル・サウンド・ノッチ・モーター音が見つからないときは、開いた直後に「まとめて新しく作りますか？」と尋ねます。「はい」で、ヘッダーだけ入れたファイルを作って各タブに読み込みます
  - パラメーターとノッチは BVE で必ず必要なファイルです（参照欄に「必須」と表示）。書かれていない・見つからないときや、パスが1つも書かれていないときは警告します
  - パラメーターとノッチの参照欄は、ファイルを読み込めるまで色付きの枠線で目立たせます（読み込めると消えます）
  - 「参照」ボタンでファイルを選ぶと、車両ファイルにそのパス（相対パス）を書き込みます。Ctrl+Z で元に戻せます。選んだファイルの中身は、すぐ各タブに読み込まれます（そのタブに保存していない変更があれば確認します）
    - ファイルを選ぶ画面でまだない名前を打つと、新しく作るか尋ねます。「はい」で、ヘッダーだけ入れたファイルを作ります（フォルダーがなければ一緒に作ります。同じ名前のファイルは上書きしません）
- パラメーターのタブでは、先頭車・応荷重制御・運転台（ハンドルの種類、ノッチ数、ノッチのテキストなど）・定速運転装置（力行中・惰行中・ブレーキ中の制御を 0～3 から選ぶ）・主制御装置（電気ブレーキの速度、ハンドルの遅れ、ブレーキ優先など。数字の欄の右に単位）・再粘着制御（「使う」チェックでセクションを足す・消す）・ブレーキ方式（電気指令式・電磁直通・自動空気を選ぶ。その方式で使えない項目は灰色）・直通管の圧力調整弁 [Sap]（電磁直通のときだけ）・釣り合い空気溜めの圧力調整弁 [Er]（自動空気のときだけ）・ブレーキ管の圧力調整弁 [Bp]（電磁直通・自動空気）・電空協調制御（遅れ込め制御式・締切電磁弁式を選ぶ）・ブレーキシリンダーの圧力調整弁（開・閉切り替え式 [BC]・圧力比例制御式 [BcServo] を選ぶ。どちらも書かれていなければ仮に [BcServo] として扱う。受圧面積はヘッダーが 2.00 以降なら灰色）・基礎ブレーキ装置 [Brake]（受圧面積と制輪子の摩擦係数。摩擦係数は a, b, c を1行ずつの欄に分けて入れ、速度ごとの摩擦係数 μ を表で見せる。ヘッダーが 1.01 以下なら摩擦係数は灰色）・滑走再粘着制御 [BrakeReAdhesion]（「使う」チェックでセクションを足す・消す。ヘッダーが 1.01 以下では使えない）・空気圧縮機 [Compressor]（始動する圧力・停止する圧力・圧力が上がる速さ。始動が停止以上なら警告）・力学パラメーター [Dynamics]（質量・両数・慣性係数・車両長・走行抵抗の a, b, c・曲線抵抗の係数。抵抗の係数は、書かれていなければ質量・両数から計算した既定値を出す）・乗客 [Passengers]（定員・乗客 1 人の質量・乗車と降車の速さ）・客室ドア [Door]（閉まるのにかかる時間）・運転士の視点 [ViewPoint]（X・Y・Z。マイナスも書ける）を入力フォームに表示します
  - ヘッダーが古い（1.01 以下）パラメーターファイルでは、そのバージョンで使えない項目を灰色にして知らせます（書かれていない項目は「（既定: 8）」のように、BVE が使う既定値を薄く出します）
  - [Cab] も [OneLeverCab] も書かれていないときは、BVE と同じく既定のツーハンドル [Cab] として扱います。値を入れると [Cab] ごと足します
  - フォームで変えると下のテキストが書き換わります（行がなければ足します。テキストをクリックして Ctrl+Z で戻せます）
  - 数字や文字の欄は、Enter を押すかほかの欄へ移ると書き込みます（Esc で取り消し）。何も打たずに Enter やほかの欄へ移っても、何も書き込みません。ハンドルを切り替えると [Cab] と [OneLeverCab] が書き換わります
  - ノッチ数がノッチのテキストの数より多い、ATS キャンセルノッチやモーターブレーキノッチがブレーキノッチ数より大きい、数字でない、レバーサーのテキストの最後に「,」がある（BVE で文字が壊れる）、といったときは、運転台の枠の上に警告を出します
  - 公式の一覧にないセクション名・キー（MotorcarWieght のような書き間違い）は、フォームの一番上に行番号つきで警告します。パネル・ノッチ・モーター音のタブも同じように警告します
  - 同じセクション（[Dynamics] など）が 2 回以上書かれているときは、フォームの一番上に行番号つきでお知らせを出します（このアプリは 2 つを合わせて読み、同じキーは下の行の値を使います）。ノッチ・モーター音の [Power]・[Brake]、パネルの [This] も同じように知らせます（パネルの [This] は別々のセクションとして出します）。サウンドは分けて書いた車両もあるので知らせません
  - 比べる値の片方が書かれていないときは、BVE が使う既定値で比べます（例：「ブレーキノッチ数（書かれていないので既定の 8）」）。空気圧縮機の始動と停止の圧力も同じです
- パネルのタブでは、上の「セクション」の欄で [This]・[Needle] などを選ぶと、そのセクションに書かれている値を表示します
  - [This] を選ぶと、解像度・表示できる限界・昼夜の画像・透過色・画面の中心・消失点・パースの強さを欄で変えられます（下のテキストが書き換わり、Ctrl+Z で戻せます）。数字でない・「x, y」の形でない・色が 6 桁の 16 進数でないときは警告します
  - 計器（[PilotLamp]・[Needle]・[DigitalNumber]・[DigitalGauge]）を選ぶと、表示する状態量・位置・昼夜の画像・透過色・描画順序を欄で変えられます。同じ名前のセクションが何個あっても、選んだセクションの中だけが書き換わります（[DigitalGauge] には画像の欄はありません）
  - 計器ごとの項目も欄で変えられます。[Needle] は色・回転中心・半径・角度・最小最大・傾き・可動範囲の制限（チェック）・固有角振動数・減衰比、[DigitalGauge] は LED 消灯の色・半径・角度・最小最大・傾き・分解能、[DigitalNumber] は 1 コマの高さ
  - 表示する状態量（Subject）は、「一覧から選ぶ ▼」で kmph（速度）・bc（ブレーキシリンダ圧力）・ats0 などから選べます。欄の下に説明が出ます。一覧にない名前、ATS の番号が 0～255 の外、ブレーキ方式が電気指令式なのに sap・bp・er を使うときは警告します
  - 欄にないキー（書き間違えなど）は「そのほかの項目」に表示します
  - ヘッダーが 2.00 や Version 1.0 のときは、2.01 からの項目（パースの強さ・傾き・可動範囲の制限）を灰色にして知らせます
  - 2.00 以降で色の前に「#」を付けている（コメントになって読まれない）、画像ファイルが見つからない、描画順序が 0～255 の整数でない、といったときは警告します
  - 画像の幅・高さが 2 のべき乗（64・128・256 …）でないときは、お知らせを出します（DirectX の仕様で、画像が間延び・縮んだり崩れたりすることがあるため）
  - 同じ名前のセクションは「[Needle] 1つ目」のように番号を付け、行の後ろのコメントと表示する状態量（Subject）も一緒に出します（例：「[PilotLamp] 2つ目：知らせ灯（ats19）」）
  - 選ぶと、下のテキストがそのセクションの行まで動きます
  - 「セクションを足す ▼」で [This]・[PilotLamp]・[Needle]・[DigitalNumber]・[DigitalGauge] をテキストの最後に足せます（[This] は1つだけ）。「このセクションを消す」で、選んでいるセクションだけを確認してから消せます（Ctrl+Z で戻せます。セクションの前の区切りのコメント行は残します）
  - [This] がないときは、BVE で運転台が丸ごと見えなくなるので警告します
  - 古い形式（Version 1.0）のパネルでは「BveTs Instrument Panel 2.01 に書き直す」ボタンが出ます。押すと、確認してからヘッダーを書き換え（Shift_JIS のファイルなら :shift_jis を付ける）、色の前の「#」を外します（Ctrl+Z で戻せます）。色のほかに「#」がある行は、行番号を知らせます
- ノッチのタブでは、[Power]（力行）と [Brake]（ブレーキ）の表のファイル（進段パラメーター・引張力 空車／満車・電流 空車／満車・無負荷電流）のパスを表示します
  - 「参照」で CSV などのファイルを選ぶと、Notch.txt からの相対パスが下のテキストに書き込まれます（行がなければ足します。Ctrl+Z で戻せます）
  - 見つからないファイルや、使えない文字が入ったパスは、色を変えて警告します
  - 「開く」で、表のファイルを別のウィンドウで表の形で見られます。左の「行」「速度」の列は横に動かしても見えたままで、「#」で始まるコメントの行は灰色で出ます
    - セルをダブルクリック（または F2・文字を打つ）で直せます。Enter で決まり、Esc でやめます
    - 「保存」か Ctrl+S で、そのファイルだけを元の文字コードで保存します（直していない行・行の後ろの「,」・改行の形は元のまま）。保存していないとウィンドウの名前に「*」が付き、閉じるときに確認します
    - Delete キーで、選んだセルの中身を空にします。「ノッチ 1」などの見出しをダブルクリックすると、その列を全部選びます（「行」の見出しは表全部）
    - Ctrl+Z で元に戻し、Ctrl+Y（または Ctrl+Shift+Z）でやり直せます（セルを直す・空にする・貼り付け・行や列を足す・消す・式から作る。100 回分）
    - 表の中で右クリックすると、元に戻す／やり直す、行を上・下に足す／選んだ行を消す、列を左・右に足す／選んだ列を消す、中身を空にする、切り取り・コピー・貼り付け（Ctrl+X / Ctrl+C / Ctrl+V。Excel とやり取りできます）が使えます
    - 引張力・電流の表では「グラフ」のタブで、速度ごとの値をノッチごとの線のグラフで見られます。マウスを乗せると近い点の値が吹き出しで出て（吹き出しの色はライト・ダークに合わせます）、ホイールで拡大・縮小、右ボタンのドラッグで移動、ダブルクリックで元に戻ります（グラフの部品は OxyPlot）
      - ウィンドウが狭いとき（グラフの幅 700 未満）は、凡例をグラフの下に横に並べます。ノッチ・段ごとの線が多いとき（広いとき 20 本、狭いとき 8 本より多い）は、その線を凡例に出しません（線にマウスを乗せると名前が出ます）。「式から作る」「抵抗制御で作る」のグラフも同じです
      - 抵抗制御のサンプルのように、使わない速度にとても大きい値（3.8 × 10¹⁸ など）を入れた表では、その値を除いて縦の軸の上限を決めます（軸の名前に「とても大きい値は軸の外」と出ます。表の中身は変わりません）
    - 力行の表（引張力・電流の空車と満車、無負荷電流）では「式から作る…」で、ノッチごとの起動加速度・v1（定トルクの終わり）・v2（定電力の終わり）・減衰の指数 k・起動時の電流から、M 車 1 両あたりの表を作れます
      - 編成の重さ・両数・慣性係数、乗客の定員・体重とノッチ数はパラメーターから読みます。値を変えるとグラフのプレビューがすぐ変わります（引張力では走行抵抗も灰色の点線で出ます）
      - 満車は乗車率から重さの比で増やし、増やす速度の上限も入れられます。満車の電流は倍率、無負荷電流は「下がり始める速度 v0」から先を速度に反比例で下げます
      - 「作る表」をチェックすると、まとめて作れます。開いている表は画面の表を置き換え（保存するまでファイルは変わりません）、ほかの表は確認してからファイルに直接書きます（前の中身は同じフォルダーに「○○.日時.bak」で残ります）
      - 入れた値は、アプリを閉じるまで覚えておきます（力行とブレーキは別々）
    - ブレーキの表（引張力・電流の空車と満車、無負荷電流）でも「式から作る…」が使えます。ノッチごとの減速度・vs（効き始める速度）・va（最大になる速度）・vb（弱め始める速度）・減衰の指数 k・最大の電流から作ります（0～vs は 0、vs～va は直線で上げる、va～vb は一定、vb より上は速度の k 乗に反比例。電流は力に比例）。最初はノッチ 1 つです
    - 力行・ブレーキの引張力・電流の表では「抵抗制御で作る…」で、抵抗制御（直並列・弱め界磁・発電ブレーキ）の車両の、列が進段（段）ごとの表を作れます。ブレーキの表で押すと、ブレーキ用の画面が開きます（下の「ブレーキ」）
      - 段の数（直列 S・並列 P・弱め界磁 WF）と限流値は進段パラメーターから、全界磁の点（全並列・全界磁の段で限流値まで下がる速度と力）と弱め界磁の界磁の割合は今の表から読みます。電動機の形（飽和 s・中の抵抗 r・損失 L）を直すと、段ごとの線と「全ノッチで走ったとき」の線（式は太い実線、今の表は太い破線）のグラフがすぐ変わります
      - 「今の表に合わせる」で、今の表に一番合う全界磁の点・界磁の割合・s・r・L を選び直します。0 から加速したときの到達時間も合うように選び、段ごとの切り替わる速度（今の表の値を写したほうが合うとき）・直列の電圧の割合・弱め界磁だけの飽和 s・中の抵抗 r・力 q も入ります
      - 開いたとき、起動の段の数と直列の電圧の割合も今の表から入れます。今の表の「全ノッチで走ったとき」の線は、行と行の間もつないで BVE と同じように段を進めて描きます
      - 引張力・電流の空車と満車（満車は空車と同じ値）をチェックして、まとめて作れます。段の数が進段パラメーターの列の数と違うときは知らせます
      - ブレーキ（発電ブレーキ）：段の数と段ごとの限流値は進段パラメーターから、限流値の力と段ごとの切り替わる速度は今の表から読みます。段 1 がいちばん速い速度で使われ、電流が限流値まで下がると次の段へ進みます。グラフは段ごとの線（B1…）と「全ノッチで走ったとき」（式と今の表）です
      - ブレーキの「今の表に合わせる」で、飽和の強さ s・電圧の下がり b（速いほど電流が増えにくい）・限流値より上の飽和・限流値の力・段ごとの切り替わる速度を選び直します。入れた値は力行と別に覚えます
    - 表の上のボタンで、行を足す・消す、列（ノッチ。モーター音の表では音）を足す・消すことができます（選んでいるセルの行・列が対象。消すときは確認します。1 列目は消せません）
    - 数字でないセルがあると、上に「⚠ 数字でないセル：3 行目のノッチ 1「12.5a」」のように警告します（コメントの行と、進段パラメーターの項目名は調べません）
    - 1 列目（速度。進段パラメーターは項目名）だけ書いて 2 列目から全部空の行は「値が空の行（BVE でエラーになります）」、1 列目が空なのに値が入っている行も警告します（後ろのノッチだけ空の行と、全部空の行は警告しません）
    - 進段パラメーターを開くと、「項目」の右に「単位・説明」の列が出ます。一覧にない項目名（BVE でエラーになります）や、同じ項目名が 2 回あると警告し、ヘッダーより新しい項目（例：1.00 の ResetTime）や書かれていない項目はお知らせで知らせます
    - 書かれていない項目があるときは「足りない項目を足す」ボタンが出ます。押すと確認してから、最後のデータの行の下に値 0 で足します（足したあとで値を直してください）
- モーター音のタブでは、[Power]（力行）と [Brake]（ブレーキ）の音量（Volume）とピッチ（Frequency）の表のファイルのパスを表示します
  - 「参照」で CSV などのファイルを選ぶと、MotorNoise.txt からの相対パスが下のテキストに書き込まれます（Ctrl+Z で戻せます）。見つからないファイルは色を変えて警告します
  - 「開く」で、ノッチと同じ表のウィンドウで見て・直して・保存できます。列は Motor0.wav・Motor1.wav … に合わせて「音 0、音 1…」です。「グラフ」のタブでは、速度ごとの音量・ピッチを音ごとの線で見られます
  - 表の上に、音量が 0～1 でないセル・ピッチがマイナスのセルを警告します。値が入っている音の列が Sound.txt の [Motor] に書かれていない（その音は鳴らない）ときは、お知らせで知らせます
- サウンドのタブでは、上の「セクション」の欄で [Run]（走行音）・[Horn]（警笛）・[Door]（客室ドア）など 17 のセクションを選ぶと、その音のファイル（wav）のパスを表示します（セクションの名前の後ろに、書かれている数か「なし」が出ます）
  - [Pilot Lamp]・[Brake Handle]・[Master Controller] のように空白を入れたセクション名（公式の英語版のページの書き方）も、同じセクションとして扱います。古い名前の [Switch]・[Suspension]・[Rolling] も、[Joint]・[AirSpring]・[Run] として扱います。参照ボタンで選ぶと、書かれているとおりの名前のセクションの中に書きます。[PilotLamp] と [Pilot Lamp]（[Joint] と [Switch] など）の両方があるときは警告します
  - [Horn] など名前で書くセクションはキーごとに、[Run]・[Ats] など番号で書くセクションは書かれている番号ごとに行が出ます。書かれていないキーは、欄に何の音か（例：「警笛 2（キーを押した時）」）を薄く出します
  - 「参照」で wav を選ぶと、Sound.txt からの相対パスが下のテキストに書き込まれます（行やセクションがなければ足します。Ctrl+Z で戻せます）
  - 見つからないファイルや、使えない文字・名前の最後のピリオドなどがあるパスは、どのセクションの分もまとめて上に警告します
  - [Run]・[Ats] など番号のセクションでは、下の「番号」に番号を入れて「この番号で音を選ぶ…」を押すと、「番号 = パス」の行を足せます（最初は書かれているいちばん大きい番号の次が入っています。整数でない、ATS で 256 以上、もう書かれている番号のときは知らせます）
  - どの行も「消す」で、確認してから下のテキストからその行を消せます（セクションの行と wav のファイルは消しません。Ctrl+Z で戻せます）
  - 「▶」で音を鳴らして確かめられます。鳴らしている行は「■」になり、もう一度押すと止まります（ほかの行の ▶ を押すとそちらに替わり、ほかのタブへ移ると止まります）
    - 鳴らせないときは、すぐに理由を知らせます：Windows のサービス「Windows Audio」「Windows Audio Endpoint Builder」が止まっている（開始には管理者の権限が要ります）、音の出る機器（スピーカー・ヘッドホン）がない・無効、ファイルが wav の形でない（壊れている）
  - 公式の一覧にないセクション・キー、番号のセクションの整数でないキー、[Ats] の 256 以上も、行番号付きで警告します（古い形式「Version 1.0」のファイルは調べません）
  - 古い形式（1 行目が「Version 1.0」）のファイルでは「BveTs Vehicle Sound 3.01 に書き直す」ボタンが出ます。押すと、確認してから 1 行目だけを書き換えます（Shift_JIS のファイルなら :shift_jis を付けます。中身は変えません。Ctrl+Z で戻せます）。書き直すまで、参照・消す・番号を足すは使えません
  - ヘッダーのバージョンで使えないキー（3.00 以前の ApplyFast・ReleaseFast・UpFast・DownFast、2.0 の BpDecomp）は灰色になり、「※ BveTs Vehicle Sound 3.01 から使えます」のように出ます。書かれているときは警告します
- 車両ファイルに書かれたパス（`../` を含む相対パスも可）で、パラメーター・パネル・ノッチ・モーター音・サウンドを各タブに読み込みます
- 「すべて保存」では、読み込めたファイルだけを元の場所・元の文字コードで保存します（見つからなかったファイルを空で作ることはありません）
  - 変更がないファイルは保存しません。保存したファイルの名前は、ステータスバーに 5 秒だけ「保存しました：Vehicle.txt ほか 2 つ」のように出します（問題なく開けたときも「読み込みました：○○」と出します）
- 保存していない変更があるタブは、名前の右上に小さな「*」が付きます（タブの幅は変わらないので、ウィンドウが細くてもタブが2段になりません。マウスを乗せると「保存していない変更があります」と出ます）
  - 保存していないままアプリを閉じようとすると、「保存して終了／保存せずに終了／キャンセル」を選べます
  - 保存していないまま別の車両ファイルを開こうとしたときも、同じように選べます
- ステータスバーの右端に、今開いているタブのファイルの文字コード（UTF-8 / UTF-8（BOM 付き） / Shift_JIS）を表示します。保存するときもこの文字コードです。その隣に改行の形（CRLF / LF / CR、混ざっていれば「混在」）も出します
  - プロジェクトの場所が長いときは「…」で省略し、マウスを乗せると全部見えます
- 「ファイル → 文字コード」で、今開いているタブのファイルを保存するときの文字コード（UTF-8 / UTF-8（BOM 付き） / Shift_JIS）を変えられます。変えると未保存（*）になり、「すべて保存」でその文字コードになります
  - Shift_JIS で書けない文字（絵文字など）があるときは、文字化けを防ぐため変えません
  - ヘッダーの文字コード指定も合わせて書き換えます（Shift_JIS なら `:shift_jis` を付け、UTF-8 なら外します）。Ctrl+Z で戻せます
- タイトルバーに、開いている車両ファイル名を表示します（例：「BveVehicleEditor - Vehicle_A0.txt」。保存していない変更があると最後に「*」）
